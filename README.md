# Jivan Warankar - Professional Developer Portfolio

A premium, responsive, personal developer portfolio website built for **Jivan Warankar**, an IT Graduate and Aspiring Software Developer.

This application is built with **React + TypeScript + Vite** and styled using **Tailwind CSS v4** and custom CSS design guidelines.

## 🚀 Live Demo & Development Server
To launch the website locally, install dependencies and start the development server:
```bash
# Install packages
npm install

# Start Vite dev server
npm run dev
```

---

## 🎨 Key Features & Sections
- **Interactive mock IDE window**: Code tabs showcasing standard details in Javascript and skills structures in JSON formats.
- **Visual gallery slide deck**: A 3D cards stack showcase with play/pause slideshow intervals, arrow navigation, and responsive thumbnails.
- **Full-screen Lightbox viewer**: Zoom modal containing click-out functions, blur, and high resolution views.
- **Responsive design**: Works across wide desktop formats, tablet drawers, and mobile grids.
- **Dual layout support**: Switch between Dark and Light mode themes.
- **Academic timeline**: Interactive timeline of education degrees, coursework certificates, and qualifications.
- **Recruiter CTA**: Dedicated resume download triggers and validation-ready contact forms.

## 📂 Project Structure
